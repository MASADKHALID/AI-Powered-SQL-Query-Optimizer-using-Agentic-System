Step 1 — Enable TCP/IP in SQL Server

Press Windows key → search "SQL Server Configuration Manager" → open it
On the left click SQL Server Network Configuration
Click Protocols for MSSQLSERVER (or SQLEXPRESS)
Right-click TCP/IP → click Enable
Click OK


Step 2 — Set port to 1433

Right-click TCP/IP again → click Properties
Click the IP Addresses tab
Scroll down to IPAll section
Set TCP Port to 1433
Clear TCP Dynamic Ports (delete anything in that box)
Click OK


Step 3 — Restart SQL Server

On the left click SQL Server Services
Right-click SQL Server (MSSQLSERVER) or SQL Server (SQLEXPRESS)
Click Restart


Step 4 — Allow port 1433 in Windows Firewall

Press Windows key → search "Windows Defender Firewall"
Click Advanced Settings
Click Inbound Rules → New Rule
Select Port → Next
Select TCP → type 1433 → Next
Select Allow the connection → Next
Check all 3 boxes → Next
Name it SQL Server 1433 → Finish

SELECT @@SERVERNAME

Port           →  1433
Username       →  mylogin
Password       →  your password
Database Name  →  myDatabase

Step 2 — Test the schema endpoint

Click POST /schema
Click Try it out
Paste this (use your exact details):

json{
  "db_type": "mssql",
  "host": "<SELECT @@SERVERNAME>",
  "port": 1433,
  "username": "<usenmae>",
  "password": "<your password>",
  "database": "<database name>"
}

Click Execute


If it is really connected you will see your actual tables:
json{
  "tables": {
    "table1": { "columns": [...] },
    "table2":    { "columns": [...] },
    "table3":  { "columns": [...] }
  }
}
If database is empty you will see:
json{
  "tables": {}
}
This still means connection works ✓ — just no tables yet.
If connection failed you will see:
json{
  "detail": "MSSQL Error: ..."
}
